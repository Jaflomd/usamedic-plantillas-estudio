# Plantillas de Estudio · USAMEDIC

Galería de **22 plantillas de estudio** para medicina, organizadas por concepto y
diseñadas para **recuerdo activo**. Cada plantilla es una página HTML autocontenida:
editable en el navegador, con autoguardado local y exportable a PDF.

🔗 **Sitio en vivo:** https://jaflomd.github.io/usamedic-plantillas-estudio/

## Qué es

Cada concepto médico tiene su plantilla con los campos canónicos del sistema de
metadata de estudio, y por cada campo: un **rol**, una **esencia**, **preguntas
guía de alto rendimiento** (disparadores de recuerdo activo) y un área editable.

Orientadas a la preparación **ENAM / Residentado Médico** (Perú).

## Dominios y plantillas

| Dominio | Plantillas |
|---|---|
| Estructura & Anatomía | Anatomía · Célula · Zona anatómica · Órgano · Músculo · Par craneal |
| Fisiología & Biomolecular | Hormona · Receptor · Molécula · Gen |
| Patología, Clínica & Microbiología | Guión de Enfermedad · Abordaje DETS · Enfermedad · Utilidad · Signo · Microorganismo |
| Farmacología | Droga · Familia farmacológica · Vacuna |
| Diagnóstico & Procedimientos | Procedimiento · Lab · Descriptor |
| Razonamiento & Sistemas | Pensamiento en Sistemas |

Dos plantillas insignia para el concepto **Enfermedad**:
- **Guión de Enfermedad** — entenderla: Fisiopatología → Epidemiología → Curso → Presentación Clínica.
- **Abordaje DETS** — actuar sobre ella: **D**iagnóstico → **E**stadiaje/Clasificación → **T**ratamiento → **S**eguimiento.

## Cómo se usa

1. Abre [`index.html`](https://jaflomd.github.io/usamedic-plantillas-estudio/) (la galería).
2. Entra a la plantilla del tipo de tema que estudias.
3. Escribe directamente en los campos — se **autoguarda** en tu navegador (localStorage).
4. Usa **Imprimir / PDF** para exportar la plantilla llena.

## Notas técnicas

- HTML estático, sin dependencias ni build (solo Google Fonts: Montserrat + Poppins).
- Identidad visual **USAMEDIC** (logos en `assets/`).
- El autoguardado es por dispositivo/navegador; no hay servidor ni datos en la nube.
